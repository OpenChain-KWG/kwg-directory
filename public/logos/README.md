# KWG Directory 로고 사용 가이드

## 파일별 사용 상황
| 파일 | 사용 상황 |
|---|---|
| kwg-icon.svg | 앱 내 아이콘, SNS 프로필 사진 |
| kwg-horizontal.svg | 네비게이션 바, 공식 문서 헤더 |
| kwg-favicon.svg | 브라우저 탭, 모바일 홈 화면 |
| kwg-icon-dark.svg | 어두운 배경 위 사용 |

## 사용 규칙
- 로고 색상 및 비율 변경 금지
- K 모티프와 노드 요소 분리 사용 금지
- OpenChain 공식 로고와 혼동되게 배치 금지
- 최소 사용 크기: 아이콘형 24×24, 가로형 120×32
