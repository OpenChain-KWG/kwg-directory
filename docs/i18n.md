# 다국어 지원 (i18n)

## 현재 지원 언어

| 언어 | 코드 | 상태 | 번역 완성도 |
|------|------|------|------------|
| 한국어 | `ko` | ✅ 완료 | 100% |
| 영어 | `en` | 🚧 번역 기여 모집 중 | 0% |

---

## 번역 파일 구조

```
messages/
├── ko.json    ← 기준 언어 (한국어, 변경 금지)
└── en.json    ← 번역 대상 (빈 값 채우기)
```

각 파일은 동일한 키 구조를 공유합니다. 값이 비어 있으면 자동으로 `ko.json`의 값이 폴백으로 사용됩니다.

---

## 번역 기여 방법

### en.json 번역 기여

1. 저장소를 포크합니다
2. `messages/en.json`을 열어 빈 문자열(`""`)을 영어로 채웁니다
3. PR을 생성합니다 (제목 예: `feat(i18n): add English translations`)

### 번역 가이드라인

- `{variable}` 형식의 변수는 그대로 유지하세요
  - 예: `"memberCount": "OpenChain KWG Members: {count}"` ✅
  - 예: `"memberCount": "OpenChain KWG Members: count"` ❌
- 줄바꿈 `\n`이 포함된 값은 동일하게 유지하세요
- UI 공간 제약을 고려해 간결하게 번역하세요
- 번역이 불확실한 경우 주석 대신 ko.json 값을 그대로 사용하세요

### 번역 예시

```json
// ko.json (기준)
"loginButton": "GitHub으로 로그인"

// en.json (번역)
"loginButton": "Sign in with GitHub"
```

## 새 언어 추가 절차

현재 i18n 라이브러리가 미설치 상태입니다. 번역 기여가 충분히 쌓이면 `next-intl` 라이브러리를 도입할 예정입니다.

향후 구현 예정 단계:

1. `npm install next-intl` 설치
2. `next.config.ts`에 i18n 라우팅 설정 추가
3. `messages/{locale}.json` 파일 추가
4. 컴포넌트에서 `useTranslations()` 훅으로 교체

새 언어 추가 시 Issue를 먼저 등록해 번역 진행 상황을 공유해주세요.

---

## 번역 기여 이슈 등록

새 언어 번역을 시작하려면 아래 제목으로 Issue를 등록하세요:

```
[i18n] {언어명} 번역 기여
예: [i18n] Japanese translation
```

담당자 지정 후 번역 진행 상황을 이슈에서 추적합니다.
